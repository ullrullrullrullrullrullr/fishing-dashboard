# 釣行前チェック

鶴岡周辺(由良・加茂・鼠ヶ関)の堤防釣り向けに、風・突風・波・うねり・雷から、釣りに行けそうかの目安を出す iPhone 用のウェブアプリ。

## 使い方

1. iPhone の Safari で、このページの URL を開く。
2. 画面下の「共有」ボタン(四角から矢印が出ているマーク)を押す。
3. 「ホーム画面に追加」を押して、「追加」を押す。
4. ホーム画面に「釣り前」のアイコンができる。これを押すと、アプリのように開く。

**最初の1回は、電波のあるところで、ホーム画面のアイコンから開いてください。**

- 一番上の大きな枠が、その日の目安。「条件は良さそう」「注意」「やめた方がいい」「不明」のどれか。
- 「不明」は、データが取れていないか古いときに出ます。そのときは、自分の目で波と風を見て判断してください。
- 目安は予報にもとづくもので、堤防の上の安全を保証しません。波は沖の予報値です。必ず現地で波と風を見て、ライフジャケットを着けてください。
- 冬(11月〜3月)は、日本海が荒れやすいので、「注意」や「やめた方がいい」になりやすいと考えられます。
- 判定の基準値は、釣り情報サイトの目安をもとにした仮の値で、公的な基準ではありません。

## データ元

- 天気・波: [Open-Meteo.com](https://open-meteo.com/)(CC BY 4.0)
- 潮汐・月齢・日の出日の入り: [tide736.net](https://tide736.net/)
